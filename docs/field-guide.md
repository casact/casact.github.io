# Field Guide

A great deal of actuarial software already exists, more than most actuaries
realize. This page is a map of it, organized the way the question usually
arrives: not "what is in the CAS GitHub organization" - the
[Projects](projects.md) page answers that, straight from the GitHub API - but
"I have a reserving problem, or a tail-fitting problem, and I would rather
not start from an empty file."

Two dimensions do the work here. **Functional area** groups tools by the job
they do, so a triangle question and a mortality question never sit in the
same list. **Language** tells you, before you click, whether the answer is
going to arrive in R, Python, or Julia, which in practice decides whether it
is an answer you can use this afternoon. The filters below cut the table on
both.

If a tool is missing, adding it is a one-row pull request against
[this page's data file](https://github.com/casact/casact.github.io/blob/main/docs/_data/field_guide.csv);
you do not have to touch any HTML, and the
[pull request tutorial](https://github.com/casact/pull_request_tutorial) will
walk you through the mechanics if this would be your first one.
